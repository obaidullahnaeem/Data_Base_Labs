# Database Labs

This repository contains my Database Lab work completed as part of my Computer Science degree. It includes SQL scripts and practical exercises using Microsoft SQL Server.

## Topics Covered

- Creating databases and tables
- Inserting, updating, and deleting records
- Primary keys and identity columns
- Retrieving data using `SELECT`
- Filtering data using `WHERE`, `AND`, `OR`, `IN`, `BETWEEN`, and `LIKE`
- Sorting and selecting records using `ORDER BY` and `TOP`
- Removing duplicate values using `DISTINCT`
- Aggregate functions: `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`
- Grouping data using `GROUP BY` and filtering groups using `HAVING`
- SQL functions such as `UPPER()`, `LEN()`, `ROUND()`, `CEILING()`, `YEAR()`, and `GETDATE()`
- Converting and formatting values using `CAST()` and `CONVERT()`
- Replacing text and working with strings using `REPLACE()`

## Tools Used

- **Microsoft SQL Server**
- **SQL Server Management Studio (SSMS)**
- **SQL**

## Repository Structure

The repository contains SQL scripts organized by lab number. Each script covers practical exercises, queries, or database operations related to the topics studied in that lab.

## Purpose

The purpose of this repository is to practice SQL, understand relational database concepts, and build a foundation for working with databases through hands-on exercises.

This repository will continue to grow as I complete more database labs and learn additional SQL concepts.
